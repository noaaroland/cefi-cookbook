Finding the Data You Want
===
The CEFI data collection is complex and contains multiple regions, grids, experiments, and time frequencies. This tutorial will help you find which data parameters are available at which time frequencies and for which experiment types. If you need some background, you can read up on the details of the project at the [CEFI Portal](https://psl.noaa.gov/cefi_portal/#faq) or in the model [documentation section](../../model_doc/regional_mom6_faq.md).

Beginning at the top of the colored columns in the [interactive availability matrix](https://viz.pmel.noaa.gov/cefi) you can see all of the regions available in the catalog (nep = Northeast Pacific, nwa = Northwest Atlantic, cpi = Hawaiian Islands). Below that are the experiments available for each region, and below that are the time frequencies available for each experiment, and finally whether they are available in the original raw and/or as a rectilinear regrid.

[ ![Searching for Data Availability in the NWA region](../../../images/data_availability_opening_page.png)](https://viz.pmel.noaa.gov/cefi)

Reading across the columns for a particular variable you can immediately see if it is available by the green colored cell and the "Y". The "Y" is a link to the data available for that variable, time frequency, and experiment type on earthmover.io.
